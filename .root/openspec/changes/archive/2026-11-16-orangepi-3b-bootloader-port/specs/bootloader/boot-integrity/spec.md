# Spec Delta

## Purpose

定义设备**不启用验证启动（NO AVB）**时引导程序必须满足的语义：不依赖校验分区、向系统报告未验证状态、构建配置显式关闭校验能力，以及安全执行环境固件与密钥的边界。

## ADDED Requirements

### Requirement: 未启用验证启动时报告未验证状态

引导程序 MUST 在未启用镜像校验时向系统报告"未验证"的启动状态，使系统按非锁定设备行为运行。

#### Scenario: 启动状态被系统读取

- **WHEN** 设备以未启用校验的形态启动
- **THEN** 系统可读取到"未验证"状态，并据此按非锁定设备行为运行

#### Scenario: 状态不依赖分区内容

- **WHEN** 校验分区内容任意（空、全零或残留旧数据）
- **THEN** 报告的状态保持一致，不因分区内容变化

### Requirement: 校验分区缺失或为空不影响启动

引导程序 MUST NOT 在校验能力未启用时读取校验分区，也不得要求该分区存在或包含有效数据。

#### Scenario: 校验分区为空

- **WHEN** 校验分区已分配但内容为空
- **THEN** 引导程序不读取该分区，正常装载启动镜像

#### Scenario: 校验分区不存在

- **WHEN** 分区表中没有校验分区
- **THEN** 引导程序照常启动，不报错、不中止

#### Scenario: 启动镜像不含校验页脚

- **WHEN** 启动镜像以不带校验页脚的形态构建
- **THEN** 引导程序按普通镜像处理，不推断缺失的校验信息

### Requirement: 构建配置不得启用校验能力

引导程序的构建配置 MUST NOT 启用镜像校验库与校验命令，确保产物中不存在校验逻辑。该约束 SHOULD 在板级配置中显式声明，避免被默认值或后续继承开启。

#### Scenario: 干净构建产物不含校验逻辑

- **WHEN** 从板级配置重新生成构建配置并检查
- **THEN** 校验库与相关命令均未启用

#### Scenario: 默认值变化时被发现

- **WHEN** 上游把校验能力改为默认开启
- **THEN** 板级配置中的显式关闭声明生效，构建产物仍不包含校验逻辑

### Requirement: 安全执行环境固件在引导阶段装载

引导程序 MUST 在引导阶段装载安全执行环境固件，并按约定为其保留专用内存区域；该区域大小 MUST 与系统侧保留一致。

#### Scenario: 安全执行环境可用

- **WHEN** 系统启动并探测安全执行环境
- **THEN** 探测成功，安全监控调用可用

#### Scenario: 保留区域大小不一致

- **WHEN** 引导阶段保留的内存区域小于系统侧声明
- **THEN** 系统侧安全内存与普通内存冲突，需在联调阶段修正

### Requirement: 固件与密钥不作为仓库内容

引导程序仓库 MUST NOT 包含安全执行环境二进制、平台固件或任何签名密钥；这些输入通过构建参数提供。

#### Scenario: 干净检出即可编译

- **WHEN** 从仓库重新检出代码
- **THEN** 仓库中不存在固件二进制与密钥，构建时通过外部参数注入

#### Scenario: 固件版本可追溯

- **WHEN** 需要确认某次构建使用的固件版本
- **THEN** 可从构建记录中的外部参数确定，而不是从仓库内容推断
