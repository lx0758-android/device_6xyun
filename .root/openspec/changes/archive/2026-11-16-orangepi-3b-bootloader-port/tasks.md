# Tasks

## 1. 现状核对（当前实现已满足）

- [X] 1.1 核对 defconfig 启用 bootstd 全功能与 Android 启动方式，启动命令为扫描式自动启动、延迟为零
- [X] 1.2 核对启动模式由 `misc` 引导控制块驱动，覆盖正常、恢复、fastbootd、一次性引导程序四种模式
- [X] 1.3 核对非 A/B 形态下直接使用无槽位后缀的启动分区，不注入槽位后缀
- [X] 1.4 核对"强制正常启动"标记仅在正常启动模式注入，其余模式不注入
- [X] 1.5 核对 `vendor_boot` 装载地址由板级环境文件提供且非零
- [X] 1.6 核对启动参数包含设备序列号、引导程序版本与未验证状态，且通用 Linux 命令行为空
- [X] 1.7 核对未压缩内核不满足 2 MB 对齐时回退到约定装载地址
- [X] 1.8 核对 `vendor_boot` 设备树偏移使用"头部大小按页大小向上对齐"计算
- [X] 1.9 核对设备树保留区越界条目被跳过且不中断启动
- [X] 1.10 核对板型探测同时设置引导用设备树文件名与 Android 设备树索引，顺序为 0=v1.1、1=v2.1
- [X] 1.11 核对 USB 控制器为双角色且同端口主机控制器关闭，fastboot 命令与 OEM 格式化可用
- [X] 1.12 核对退回芯片下载模式的命令可用，其地址来自 SoC 级默认配置
- [X] 1.13 核对引导环境持久化在 eMMC，默认值来自板级环境文件
- [X] 1.14 核对未启用镜像校验、系统可读取到未验证状态
- [X] 1.15 核对安全执行环境固件由构建参数注入，仓库内无二进制与密钥
- [X] 1.16 核对构建配置未启用校验库与校验命令，产物中不存在校验逻辑
- [X] 1.17 核对未启用校验时不读取校验分区，且启动镜像不带校验页脚时按普通镜像处理
