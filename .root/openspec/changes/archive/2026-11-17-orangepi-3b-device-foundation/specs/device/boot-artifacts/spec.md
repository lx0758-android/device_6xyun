# Spec Delta

## Purpose

定义本阶段需要产出的镜像集合，以及内核、内核模块、设备树与引导程序产物如何进入这些镜像，作为后续开机阶段的基础。

## ADDED Requirements

### Requirement: 启动镜像使用版本 4 头部

启动镜像MUST使用版本 4 的头部格式，镜像内含硬编码的内核命令行与引导配置参数，且不携带校验页脚。

#### Scenario: 头部版本正确

- **WHEN** 检查生成的启动镜像头部
- **THEN** 头部版本为 4，且不存在校验相关页脚

#### Scenario: 引导配置参数进入镜像

- **WHEN** 检查启动镜像中的引导配置
- **THEN** 包含存储设备标识、硬件名称与宽容模式等启动参数

### Requirement: 厂商启动镜像承载模块与设备树

厂商启动镜像MUST承载首阶段所需的内核模块、模块加载清单与板级设备树，分区容量足以容纳全部内容。

#### Scenario: 模块随厂商镜像交付

- **WHEN** 检查厂商启动镜像内容
- **THEN** 包含内核模块与模块加载清单

#### Scenario: 设备树来自板级发布

- **WHEN** 检查厂商启动镜像中的设备树
- **THEN** 设备树与内核发布目录中的板级设备树一致

### Requirement: 内核与模块来自内核发布目录

内核镜像、内核模块与设备树MUST从内核发布目录获取，模块加载清单MUST过滤测试类模块，且模块MUST NOT被裁剪。

#### Scenario: 过滤测试模块

- **WHEN** 生成模块加载清单
- **THEN** 名称包含测试或内核单元测试标识的模块被排除

#### Scenario: 模块签名不被破坏

- **WHEN** 打包内核模块
- **THEN** 模块保持原始签名状态，未做裁剪处理

### Requirement: 设备树叠加镜像包含两个板型

MUST产出设备树叠加镜像，内含 v1.1 与 v2.1 两个板型设备树，并按此顺序排列。

#### Scenario: 两个板型可被引导程序选择

- **WHEN** 引导程序按索引取用设备树叠加镜像中的条目
- **THEN** 索引 0 对应 v1.1、索引 1 对应 v2.1

### Requirement: 引导程序产物随构建输出

构建MUST把引导加载器与引导程序镜像复制到输出目录，供刷机工具使用。

#### Scenario: 刷机包内容齐全

- **WHEN** 构建完成
- **THEN** 输出目录中存在引导加载器镜像与引导程序镜像

### Requirement: 不启用镜像校验

本阶段MUST NOT生成校验镜像，校验分区保持空置，启动镜像不带校验页脚。

#### Scenario: 校验分区空置

- **WHEN** 检查构建产物
- **THEN** 不存在校验镜像文件，校验分区在分区表中保留但内容为空
