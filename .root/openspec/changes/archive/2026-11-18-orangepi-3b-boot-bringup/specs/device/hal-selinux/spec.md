# Spec Delta

## Purpose

定义本阶段新增硬件服务所需的最小 SELinux 策略，以及"宽容模式"作为阶段性状态的边界与退出方式。

## ADDED Requirements

### Requirement: 服务执行文件具备独立标签

新增服务的可执行文件 MUST 具备独立类型标签，避免与其它厂商文件混用同一上下文。

#### Scenario: 服务启动时完成域切换

- **WHEN** 初始化进程启动新增服务
- **THEN** 服务运行在对应的服务域中，标签正确

### Requirement: 允许服务访问图形设备节点

合成器、分配器与使用图形的系统进程 MUST 具备对图形设备节点的读写权限；缺失会导致界面无法显示。

#### Scenario: 合成器打开图形节点

- **WHEN** 合成器访问图形设备节点
- **THEN** 访问被允许，界面正常显示

### Requirement: 本阶段保持宽容模式

系统 MUST 以宽容模式运行；策略违规只记录不阻断，且该状态 MUST 被标注为阶段性妥协。

#### Scenario: 策略违规不阻断开机

- **WHEN** 某服务访问未被策略显式允许的资源
- **THEN** 访问被记录，系统继续启动

#### Scenario: 收紧必须走独立变更

- **WHEN** 后续需要切换到强制模式
- **THEN** 通过独立变更实施，并同步更新本规格

### Requirement: 策略随镜像打包且可在无编译环境下加载

预编译策略 MUST 随镜像交付，保证设备启动时直接从镜像加载，不依赖编译环境。

#### Scenario: 设备自包含策略

- **WHEN** 设备使用构建产物启动
- **THEN** 策略从镜像加载，不需要外部文件
