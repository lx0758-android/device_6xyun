# Spec Delta

## ADDED Requirements

### Requirement: 运行时内存上限按设备档位显式配置

产品 MUST 显式声明运行时内存参数，不得依赖运行时默认值；默认上限过小会让系统服务在开机阶段反复回收内存并最终分配失败崩溃。

#### Scenario: 系统服务可用内存充足

- **WHEN** 系统服务在开机阶段持续分配运行时对象
- **THEN** 可用上限来自产品的显式档位配置，不出现"堆空间不足"的分配失败

#### Scenario: 未声明内存档位时的表现

- **WHEN** 产品未声明运行时内存参数
- **THEN** 运行时回落到极小的默认上限，系统服务在开机阶段崩溃，评审阶段必须检出

#### Scenario: 界面进程运行平稳

- **WHEN** 界面进程绘制并加载资源
- **THEN** 内存回收频率处于正常水平，不因频繁回收占满 CPU 而拖慢系统服务
