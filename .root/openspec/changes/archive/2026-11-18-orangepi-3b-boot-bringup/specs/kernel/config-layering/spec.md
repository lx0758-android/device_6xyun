# Spec Delta

## ADDED Requirements

### Requirement: 媒体所需的内核缓冲堆按模块补充

板级配置 MUST 以模块形式补充媒体栈所需的命名缓冲堆；缺失时媒体编码器无法获取输出缓冲，所有软件编码器统一失败，而显示通路不受影响。

#### Scenario: 编码器获取输出缓冲

- **WHEN** 软件编码器为输出码流申请缓冲
- **THEN** 命名缓冲堆存在且分配成功，编码器正常产出码流

#### Scenario: 缓冲堆缺失时的表现

- **WHEN** 板级配置未提供命名缓冲堆
- **THEN** 编码器输出缓冲申请失败并上报损坏错误，投屏与录屏无法启动，评审阶段必须检出

#### Scenario: 不污染共享内核

- **WHEN** 检查共享内核配置
- **THEN** 该缓冲堆以板级模块形式提供，共享内核仅保留缓冲堆框架本身
