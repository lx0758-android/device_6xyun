# Spec Delta

## Purpose

定义让系统完成开机所需的最小服务集合，以及明确排除的非必需服务与不适用的槽位管理能力，避免"为开机而堆服务"。

## MODIFIED Requirements

### Requirement: 提供开机必需的电源服务

设备 MUST 提供电源服务实现，且该实现 MUST 能响应模式、短时 boost 与调度提示；仅满足接口但所有 hint 都是空操作的示例实现不视为满足本要求。

#### Scenario: 系统服务完成初始化

- **WHEN** 系统服务启动并查询电源支持信息
- **THEN** 查询成功，开机流程继续

#### Scenario: 电源服务为真实实现

- **WHEN** 上层查询电源能力并下发模式或提示
- **THEN** 下发内容作用到 CPU 频率或调度参数，而非被静默丢弃

#### Scenario: 电源服务缺失

- **WHEN** 没有任何电源服务实现
- **THEN** 系统服务在初始化阶段崩溃，无法设置开机完成标志

#### Scenario: 仅提供示例实现

- **WHEN** 产品只包含示例电源服务
- **THEN** 服务可以注册，但性能提示全部空转，不满足本要求
