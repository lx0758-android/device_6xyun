# device/wired-ethernet Specification

## Purpose

定义板载有线以太网从"驱动可用"到"应用可见"的完整契约：PHY 驱动随板级模块交付、启动后网络接口存在、系统向应用声明以太网能力。

## Requirements


### Requirement: 板载 PHY 驱动随板级模块交付

板级内核 MUST 以模块形式提供板载以太网 PHY 驱动；驱动缺失时 MAC 控制器无法完成 PHY 连接，网络接口不会注册。

#### Scenario: PHY 驱动缺失

- **WHEN** 板级模块清单不包含板载 PHY 驱动
- **THEN** 网络接口不存在，系统只有回环与本地虚拟接口

#### Scenario: PHY 驱动可用

- **WHEN** 板级模块清单包含板载 PHY 驱动
- **THEN** 以太网控制器探测成功并注册网络接口

### Requirement: 启动后提供可用的有线网络接口

设备 MUST 在启动完成后提供一个处于可用状态的以太网接口，并支持链路协商与地址获取。

#### Scenario: 接口存在

- **WHEN** 系统启动完成
- **THEN** 网络接口列表中包含以太网接口

#### Scenario: 链路接入

- **WHEN** 网线接入且对端可用
- **THEN** 接口获得地址并可以访问外部网络

### Requirement: 向应用声明以太网能力

设备 MUST 声明以太网系统特性，使应用能通过特性查询识别有线网络能力。

#### Scenario: 应用查询以太网特性

- **WHEN** 应用查询系统是否支持以太网
- **THEN** 查询返回支持

#### Scenario: 仅驱动可用但未声明

- **WHEN** 接口已存在但系统未声明以太网特性
- **THEN** 依赖特性查询的应用不会展示有线网络入口，视为能力缺失
