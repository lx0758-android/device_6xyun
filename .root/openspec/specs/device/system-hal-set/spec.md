# device/system-hal-set Specification

## Purpose

定义让系统完成开机所需的最小服务集合，以及明确排除的非必需服务与不适用的槽位管理能力，避免"为开机而堆服务"。

## Requirements

### Requirement: 提供开机必需的电源服务

设备 MUST 提供电源服务实现，且该实现 MUST 能响应模式、短时 boost 与调度提示；仅满足接口但所有 hint 都是空操作的示例实现不视为满足本要求。

#### Scenario: 系统服务完成初始化

- **WHEN** 系统服务启动并查询电源支持信息
- **THEN** 查询成功，开机流程继续

#### Scenario: 电源服务为真实实现

- **WHEN** 上层查询电源能力并下发模式或提示
- **THEN** 下发内容作用到 CPU 频率或调度参数，而非被静默丢弃

#### Scenario: 电源服务缺失

- **WHEN** 没有任何电源服务实现
- **THEN** 系统服务在初始化阶段崩溃，无法设置开机完成标志

#### Scenario: 仅提供示例实现

- **WHEN** 产品只包含示例电源服务
- **THEN** 服务可以注册，但性能提示全部空转，不满足本要求

### Requirement: 提供健康服务实现

设备 MUST 提供电池与健康信息服务，供系统获取电量与健康状态。

#### Scenario: 健康信息可读

- **WHEN** 系统查询电池状态
- **THEN** 返回健康服务提供的数据，不出现服务缺失错误

### Requirement: 单槽位设备不提供启动槽位控制服务

设备 MUST NOT 提供启动槽位控制服务。单槽位、无镜像校验、无后台更新的设备不需要槽位管理；通用实现依赖槽位后缀，缺失时服务启动即失败，而它的接口声明会让存储服务在检查点探测上永久等待。重启进入引导程序由初始化进程写引导消息完成。

#### Scenario: 开机不被检查点探测阻塞

- **WHEN** 存储服务在挂载用户数据前探测检查点支持
- **THEN** 探测立即返回"不支持检查点"，不等待任何未注册的服务

#### Scenario: 重启进入引导程序

- **WHEN** 系统请求以引导程序模式重启
- **THEN** 初始化进程写入引导消息并重启，不依赖启动槽位控制服务

#### Scenario: 接口声明审查

- **WHEN** 检查设备的硬件接口声明
- **THEN** 不包含启动槽位控制接口，也不存在对应的服务与镜像组件

### Requirement: 提供密钥服务以支持数据加密

设备 MUST 提供密钥服务实现；用户数据分区使用软件加密，缺少密钥服务将无法完成挂载。

#### Scenario: 用户数据分区挂载

- **WHEN** 首阶段初始化挂载用户数据分区
- **THEN** 密钥服务可用，加密密钥正常派生

### Requirement: 明确排除非开机必需服务

本阶段 MUST NOT 引入温控服务、锁屏校验服务与媒体 DRM 服务；这些能力留到对应硬件适配阶段。

#### Scenario: 服务清单审查

- **WHEN** 审查产品服务清单
- **THEN** 不包含上述三类服务

### Requirement: 编解码器以 AIDL 方式发现

设备 MUST 将编解码器的服务发现方式配置为 AIDL；软件编解码器只注册 AIDL 服务，默认方式会看不到任何编解码器。

#### Scenario: 软件编解码器可见

- **WHEN** 媒体框架枚举编解码器
- **THEN** 软件编解码器出现在列表中，编码器列表非空

#### Scenario: 默认方式下的表现

- **WHEN** 未配置发现方式
- **THEN** 枚举结果只包含进程内少量解码器，编码器列表为空

### Requirement: 软件编码器使用图形缓冲输入面通路

软件编解码器运行在独立进程中，不提供编解码器侧输入面；设备 MUST 启用图形缓冲输入面通路，否则应用为编码器创建输入面时取不到输入面并发生空指针崩溃。

#### Scenario: 投屏或录屏创建编码输入面

- **WHEN** 应用为视频编码器创建图形输入面并开始送帧
- **THEN** 编码器正常接收图形缓冲并输出码流，进程不崩溃

#### Scenario: 未启用输入面通路

- **WHEN** 输入面通路未启用且编码器不提供自身输入面
- **THEN** 创建输入面处发生空指针崩溃并生成墓碑，评审阶段必须检出
