# device/graphics-stack Specification

## Purpose

定义设备在没有 GPU 驱动的情况下仍能完成显示合成所需的组件与属性配置：合成器、分配与映射组件、软件图形回退缺一不可，使系统界面可以正常显示。

## Requirements

### Requirement: 显示合成器基于内核显示子系统

设备 MUST 提供基于内核 DRM/KMS 的显示合成器实现，且系统 MUST 使用该实现完成界面合成。

#### Scenario: 界面正常合成

- **WHEN** 系统启动到界面阶段
- **THEN** 合成器通过内核显示子系统输出画面，不出现"找不到合成器实现"错误

#### Scenario: 合成器服务被启动

- **WHEN** 系统启动完成
- **THEN** 合成器服务处于运行状态，且其接口可被系统查询到

### Requirement: 缓冲区分配与映射组件齐备

设备 MUST 同时提供图形缓冲区分配服务、分配库与映射器三部分；缺少映射器会导致合成器启动失败。

#### Scenario: 合成器获取缓冲区

- **WHEN** 合成器请求分配图形缓冲区
- **THEN** 分配器返回可用缓冲区，映射器可将其映射给客户端

#### Scenario: 缺少映射器时的表现

- **WHEN** 映射器组件缺失
- **THEN** 合成器以"mapping 组件缺失"失败，必须在评审阶段被检出

### Requirement: 图形后端按硬件能力选择，缺失时回退软件

设备 MUST 在存在可用 GPU 驱动时使用硬件图形实现完成渲染与合成；在 GPU 驱动缺失或初始化失败时 MUST 使用软件实现，并将图形后端配置指向该实现，保证界面仍可显示。

#### Scenario: 硬件 GL 可用

- **WHEN** 系统初始化图形接口且 GPU 驱动可用
- **THEN** 图形接口解析到硬件实现，合成器成功创建硬件上下文

#### Scenario: 无 GPU 驱动不阻塞开机

- **WHEN** 系统中不存在 GPU 渲染节点
- **THEN** 系统仍能完成开机并显示界面，图形接口回退到软件实现

#### Scenario: 硬件实现初始化失败

- **WHEN** GPU 驱动存在但上下文创建失败
- **THEN** 系统记录明确错误，可通过构建配置回退到软件实现完成显示

### Requirement: 图形相关属性与屏幕密度

设备 MUST 声明图形接口版本与屏幕逻辑密度，使界面以正确比例渲染。

#### Scenario: 属性生效

- **WHEN** 系统读取图形相关属性
- **THEN** 图形接口版本与屏幕密度与配置一致，界面比例正常
