# kernel/board-devicetree Specification

## Purpose

定义板级设备树必须向系统提供的硬件描述契约，覆盖安全执行环境、重启语义、USB 角色、板级总线、存储频率与尚未移植驱动的预留节点。

## Requirements

### Requirement: 安全执行环境与安全内存保留

板级设备树 MUST 声明安全执行环境节点，并为安全管理器保留一段不可映射给普通系统的内存区域。保留区域的地址与大小 MUST 与固件侧约定一致。

#### Scenario: 安全执行环境被识别

- **WHEN** 系统启动并加载安全执行环境驱动
- **THEN** 安全执行环境设备成功探测，安全内存未被系统分配使用

#### Scenario: 固件约定不一致时暴露问题

- **WHEN** 固件使用的安全内存地址与设备树声明不一致
- **THEN** 启动日志出现安全内存冲突或驱动探测失败

### Requirement: 重启模式映射

设备树 MUST 将系统重启模式映射到平台的重启标志寄存器，至少覆盖正常重启、下载模式、恢复模式与引导程序模式。

#### Scenario: 重启进入恢复模式

- **WHEN** 系统请求以恢复模式重启
- **THEN** 引导程序读取到对应的重启标志并进入恢复模式

#### Scenario: 重启进入引导程序模式

- **WHEN** 系统请求以引导程序模式重启
- **THEN** 引导程序读取到对应的重启标志并进入引导程序模式

### Requirement: USB 控制器工作在双角色模式

承载外设功能（调试、刷机、文件传输）的 USB 控制器 MUST 工作在双角色模式，不得固定为主机模式。

#### Scenario: 设备作为 USB 外设被识别

- **WHEN** 设备通过该 USB 控制器连接到主机
- **THEN** 主机能识别到设备提供的 USB 功能

#### Scenario: 角色切换可用

- **WHEN** 系统在主机与外设角色之间切换
- **THEN** 控制器按目标角色重新枚举，无需重启

### Requirement: 板级总线按需使能

设备树 MUST 只使能板级实际使用或明确预留的总线控制器，并在无子设备时保持空总线状态。

#### Scenario: 预留总线可用

- **WHEN** 系统启动
- **THEN** 预留的 I2C 总线控制器处于使能状态且无异常日志

### Requirement: 存储控制器频率以稳定性优先

eMMC 控制器的最高频率 MUST 以当前板卡稳定性验证结果为准，不得直接采用控制器或器件规格上限。

#### Scenario: 高频导致不稳定时降频

- **WHEN** 该板卡在控制器规格上限频率下出现读写不稳定
- **THEN** 设备树采用经过验证的较低频率

#### Scenario: 调频不影响启动

- **WHEN** 设备从 eMMC 启动
- **THEN** 启动过程无存储超时或读写错误

### Requirement: 未移植驱动的节点予以保留

设备树中为尚未移植驱动而预留的节点 MUST 保留，不得因当前无驱动匹配而删除。

#### Scenario: 驱动后续移植可直接复用

- **WHEN** 后续移植对应驱动
- **THEN** 设备树节点已存在且描述了所需引脚与电源控制，无需重新补写
