# kernel/boot-observability Specification

## Purpose

定义内核启动阶段的可观测性要求：内核如何向日志输出完整的引导配置内容，以及这种明文可见性带来的敏感信息风险、适用边界与评审约束，确保调试能力与信息暴露之间的取舍可追溯。

## Requirements

### Requirement: 启动期打印完整引导配置

内核 MUST 在启动阶段将接收到的完整引导配置以明文打印到内核日志，包含条目数量、字节数与全部内容，以便核对引导程序注入的启动参数。

#### Scenario: 启动后可见引导配置

- **WHEN** 设备启动并进入内核
- **THEN** 内核日志中包含引导配置的总字节数、节点数量与完整明文内容

#### Scenario: 排查参数注入问题

- **WHEN** 引导程序注入的启动参数与预期不符
- **THEN** 可直接从内核日志逐条比对，无需额外调试手段

### Requirement: 明文打印的敏感信息边界必须被记录

由于引导配置可能包含设备序列号等标识信息，该明文打印 MUST 被明确记录为调试用途；在面向最终用户的构建中，是否关闭该输出必须在变更评审时被显式确认。

#### Scenario: 评审生产构建

- **WHEN** 准备面向最终用户的构建
- **THEN** 评审记录中包含该调试输出是否保留的决定

#### Scenario: 日志泄露风险可追溯

- **WHEN** 需要评估日志中的敏感信息暴露面
- **THEN** 可以从规格中确认该输出的存在与内容范围
